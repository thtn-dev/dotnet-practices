# 🧠 Lesson 3: Atlas Overview – Recap

## 1. Khái niệm

MongoDB Atlas là **dịch vụ MongoDB trên cloud, fully managed**.

👉 Bạn không cần:

- Cài đặt database
    
- Quản lý server
    
- Lo scaling / backup / bảo mật
    

---

## 2. Atlas cung cấp gì?

### 🔹 1. Database as a Service (DBaaS)

- Deploy MongoDB chỉ trong vài phút
    
- Chạy trên:
    
    - AWS
        
    - Azure
        
    - GCP
        

---

### 🔹 2. Cluster

- Cluster = nơi database chạy
    
- Có nhiều loại:
    
    - Free (M0)
        
    - Dedicated (production)
        

---

### 🔹 3. Automation (Tự động hóa)

- Auto scaling
    
- Auto backup
    
- Auto update / patch
    

👉 Mục tiêu: giảm DevOps

---

### 🔹 4. High Availability

- Dùng replica set sẵn
    
- Tự failover khi node chết
    

---

### 🔹 5. Security

- Authentication (user/password)
    
- IP Access List
    
- Encryption
    
- Role-based access (RBAC)
    

---

### 🔹 6. Monitoring

- Dashboard realtime:
    
    - CPU, RAM
        
    - Connections
        
    - Performance
        
- Alert khi có lỗi
    

---

### 🔹 7. Tools tích hợp sẵn

- Data Explorer (xem dữ liệu)
    
- Charts (dashboard)
    
- Atlas Search (full-text search)
    
- Data API (REST API cho DB)
    

---

## 3. Điểm khác biệt chính

👉 Atlas = MongoDB + Cloud + Automation

- Không cần quản lý infra
    
- Scale dễ dàng
    
- Dùng cho production nhanh
    

---

## 4. Tóm tắt 1 dòng

👉 **MongoDB Atlas = managed MongoDB platform giúp deploy, scale, secure và monitor database trên cloud**
